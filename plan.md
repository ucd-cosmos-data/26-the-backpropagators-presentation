# PBMC3k presentation site

The recreated site is a responsive Next.js presentation with four primary
navigation tabs: Home, Overview, Process, and Team.

Process contains six technical chapters: preprocessing, EDA, clustering,
annotation, model comparison, and further work. The site uses real results from
the PBMC3k notebooks and tables in the parent Cosmos workspace, including the
nine reviewed cell populations and model scores.

Run locally with:

```bash
npm install
npm run dev
```
